# Sistema de Gestão Educacional

Este repositório contém um **projeto acadêmico desenvolvido para a faculdade**, com foco na aplicação prática de Programação Orientada a Objetos (POO) em Java.  
O objetivo é demonstrar domínio de conceitos fundamentais de modelagem, organização em camadas, encapsulamento, herança, polimorfismo e manipulação de dados em memória.

## 🎓 Objetivo do Projeto (Acadêmico)

O projeto foi desenvolvido como parte das atividades da disciplina relacionada a desenvolvimento orientado a objetos.  
Seu propósito é **simular um sistema simples de gestão educacional**, permitindo o gerenciamento de entidades essenciais de uma instituição de ensino.

## 📚 Descrição Geral

O Sistema de Gestão Educacional permite:

- Cadastro de **alunos**  
- Cadastro de **professores**  
- Cadastro de **cursos**  
- Cadastro e gerenciamento de **turmas**  
- Registro e consulta de **avaliações / notas**  
- Listagem de entidades e consultas consolidadas  
- Execução em console (modo texto)

Todos os dados são mantidos **em memória**, pois o foco está na modelagem e construção da lógica orientada a objetos.

## ✨ Funcionalidades Principais

- CRUD completo para Aluno, Professor, Curso e Turma  
- Associação entre entidades (ex.: alunos em turmas, notas por aluno)  
- Sistema organizado em camadas e pacotes  
- Representação de regras básicas de negócio educacional  
- Classes, interfaces e abstrações utilizadas de forma pedagógica  

## 🛠️ Tecnologias e Ferramentas

- **Java** (versão usada no projeto)  
- POO aplicada na prática  
- IDE utilizada: (IntelliJ)  
- Não utiliza banco de dados (persistência em memória)
